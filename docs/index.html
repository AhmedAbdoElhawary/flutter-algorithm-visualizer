AlgoDive

Watch algorithms think.

Sorting · Pathfinding · 100 coding challenges — graded on your device, offline.

AlgoDive is an open-source Flutter app that turns sorting, pathfinding and 100 interview-style coding problems into something you can actually see — then lets you write the solution yourself. Your code is parsed, executed and graded on the phone itself, with no server and no internet connection.
